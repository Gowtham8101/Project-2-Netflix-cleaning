# 🎬 Netflix Data Analysis Dashboard | Power BI

## 📌 Project Overview
Developed an interactive Netflix dashboard using Power BI to analyze movies and TV shows, content ratings, country-wise distribution, and release year trends.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Netflix Dataset

## 📊 Dashboard Features
- **Total Titles** – KPI card showing total Netflix titles.
- **Total Movies** – Total number of movies.
- **Total TV Shows** – Total number of TV shows.
- **Movie Percentage** – Percentage of movies in the content library.
- **Movies vs TV Shows** – Donut chart comparison.
- **Ratings Analysis** – Content distribution by ratings.
- **Top 10 Countries** – Countries with the most Netflix titles.
- **Release Year Trend** – Content release trends over the years.
- **Interactive Slicers** – Country, Type, and Year.

## 🧹 Data Cleaning
- Removed duplicates and handled missing values.
- Transformed country information.
- Corrected data types using Power Query.
